# 04: 글 수정

**What to build:** 글쓴이가 Entry 카드에서 수정을 눌러 Entry Password와 새 Message를 입력하면 Message가 바뀌고 "(수정됨 수정시각)"이 표시된다. 비밀번호가 맞지 않으면 수정이 거부되고 그 카드 안에 "비밀번호가 일치하지 않습니다"가 보인다.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 올바른 비밀번호로 Message가 수정되고 목록에 반영된다
- [ ] 수정된 글에만 작성 시각 뒤 `(수정됨 YYYY-MM-DD HH:mm)`이 붙고, 작성 시각과 이름은 그대로다
- [ ] 틀린 비밀번호면 저장되지 않고 해당 카드 안에 불일치 안내가 보이며, 입력 중인 Message는 유지된다
- [ ] 새 Message도 1~500자 규칙을 적용받고, 위반 시 오류가 보인다
- [ ] 수정을 취소할 수 있다
- [ ] 이미 삭제된 글이면 "글을 찾을 수 없습니다"가 보인다
- [ ] 서버에서 비밀번호를 항상 다시 검증한다
