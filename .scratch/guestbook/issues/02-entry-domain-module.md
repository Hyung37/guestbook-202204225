# 02: Entry 도메인 모듈(검증·비밀번호)과 Vitest

**What to build:** 글 규칙을 담은 순수 모듈. 이름·메시지·비밀번호 입력 검증과 Entry Password의 해시·검증을 제공한다. DB와 Next.js에 의존하지 않는다. 이것이 프로젝트의 유일한 테스트 seam이다. `/tdd`로 테스트부터 작성한다.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Vitest가 설정되어 `npm test`로 실행된다
- [x] 이름은 trim 후 1~20자만 통과한다(경계값 0/1/20/21 테스트)
- [x] 메시지는 trim 후 1~500자만 통과하고 공백뿐이면 거부된다, 줄바꿈은 허용된다
- [x] 비밀번호는 4~72자만 통과한다(경계값 3/4/72/73 테스트)
- [x] 검증 결과는 throw 없이 필드별 오류 메시지를 담은 값으로 돌려준다
- [x] 비밀번호 해시는 평문과 다르고, 올바른 비밀번호만 검증을 통과한다
